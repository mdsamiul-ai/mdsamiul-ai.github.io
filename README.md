# Samiul Islam — GitHub Pages portfolio

A static portfolio closely matching the supplied iPortfolio reference: fixed dark sidebar, photographic hero, animated role text, About, Skills, Resume, Projects and Contact sections.

## Publish
1. Extract this ZIP.
2. Upload all extracted files to the root of your repository (not the ZIP itself).
3. In GitHub Settings → Pages, choose Deploy from a branch → main → /(root), then Save.
4. If the repository is named msamiul27.github.io, the published URL will be https://msamiul27.github.io/.

Works on project repositories too. All asset paths are relative. No Node.js, installation, build step, or API keys are required. Fonts and images are bundled.

## Customize
- Edit index.html for your profile, resume and links.
- Edit script.js for project stories and rotating role descriptions.
- Edit styles.css for styling.
- Replace the SI monogram in the sidebar and About section with your headshot when available.
- Skill labels show tools and their uses, not unverified proficiency percentages.

Professional project stories summarize publicly described work. Project covers are illustrative. No proprietary datasets or quantified employer results are included.
